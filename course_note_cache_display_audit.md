## How to read this report

- **DISPLAYED** - cached text passes current validation and current publication metadata.
- **DISPLAYABLE; app will refresh metadata** - cached text passes validation, but metadata is old; the app can refresh it and publish the note when requested.
- **CACHED, HIDDEN** - text exists, but it does not currently pass the app checks. The reason is shown; a replacement job may be pending or may need review.
- **NOT CACHED** - no cache record exists for that topic and level.
- **EMPTY/UNUSABLE CACHE** - a record exists, but it has no usable note text.
