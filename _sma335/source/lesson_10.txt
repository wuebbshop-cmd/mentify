LESSON 10
 Reduction of nth order Equations to a First order system of n
               equations and solve the system.

10.1Introduction
You have already studied different methods of solving nth order differential equations. In
this LESSON you will know a new method of solving an nth order equation.

First we reduce an nth order equation into a First order system of n linear (simultaneous)
equations using new variables and then we solve the n linear equations using the matrix
method. We revise a section of matrix algebra to find the Eigen values and the Eigen
vectors of a square matrix and use them to solve the n linear simultaneous equations. In
this LESSON we also solve nth order equations by reducing the order of the equations.

10.2Objectives of the LESSON
   •  by the end of this LESSON you should be able to: -
   •  reduce an nth order equation to a first order system of n equations.
   •   write the first order system of equations in matrix form.
   •  determine the Eigen values and the Eigen vectors of the matrix obtained.
   •  determine the solution of the  nth order homogeneous and non homogenous
       equation using the Eigen values and the Eigen vectors of the matrix.

2.11 Solution of the First Order Nonhomogeneous System of Equation

The first order non-homogeneous system of equation is of the form
           x′ = AX +B                                                (1)
where A is a constant n x n matrix. B is a vector function of t. the solution of the system
consists of two parts namely the complementary function (CF) and particular integral
(PI).   The  complementary  function XC  is  obtained  by  solving  the  associated
homogeneous system.
     x′ = AX                                                            (2)
we need to find the particular integral Xp and add it to the general solution of the system
x′ = AX. Thus the general solution of the homogeneous system is
            X = Xc + Xp                                         (3)
