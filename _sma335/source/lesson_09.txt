 9.1 Introduction
 You have already solved second order  linear homogeneous and nonhomogeneous

 9.3 Definition of a linear equation of order n
 A linear differential equation of order n has the form
   d n y    d n −1 y          dy
 a 0     n + a1     n −1 + .... + a n −1   + a n y = Q                   (1)    dx      dx            dx
 where a 0 ≠ 0 and a0, a1, a2….. an and Q are functions of x only or constants.
 If Q = 0, then the equation (1) is called homogeneous to indicate that all of the terms are
 of the same first degree in y and its derivatives.

 9.4 Solution of nth order linear equation.
 The method of solving an nth order linear equation with constant or variable coefficients
 is exactly the same as solving the second order equations.

 The solution consists of a complementary function yc and a particular integral yP.
 An nth order equation will have n independent solutions y = y1, y = y2….. yn and the
 general solution is y = c1 y1 + c 2 y 2 + ......c n y n + any particular integral.  The method of

 solving the higher order equation is illustrated in the following examples.
